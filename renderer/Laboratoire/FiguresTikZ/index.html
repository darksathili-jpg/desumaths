Le bon outil pour le bon usage

MathJax affiche les formules et démonstrations. TikZJax calcule ici des figures SVG. Le compilateur LaTeX Web produit des PDF compatibles, tandis que TeX Live natif reste nécessaire pour certains documents historiques complexes.

Cette page est un pilote : elle ne modifie ni les corrections validées ni les générateurs d'exercices. Les premiers calculs peuvent prendre plusieurs secondes ; les ressources du moteur TikZ sont servies par Desumaths.

Moteur et exemples adaptés du laboratoire original latex_tikz. TikZJax est distribué selon la licence GNU GPL version 3 ; les sources du moteur restent disponibles.
