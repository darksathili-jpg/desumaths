# Desumaths

Projet de migration contrôlée de deux sites pédagogiques vers une application de bureau Electron, prévue pour fonctionner hors ligne.

## Sources de référence

- `desumaths.zip` : interface modernisée, menus pilotés par des données ; SHA-256 `8b97c887f49cf4e6db95ba8977929f7445b92060ff96391647d6dc12a565b59f`.
- `Désusite.zip` : site historique et exercices ; SHA-256 `225fe371222240d3e6a05ac78897433df754f2ef5a8f5d90a19e5badc794538a`.

Les archives originales sont conservées séparément. Elles ne sont pas encore importées dans le dépôt. Leur audit de licences, de données sensibles, des chemins et des dépendances reste nécessaire avant import.

## Gouvernance

- G0 : inventaire, architecture cible et critères de recette (en cours).
- G1 : prototype Electron avec un exercice fonctionnel hors ligne (non commencé).
- G2 : migration et vérification mathématique des exercices.
- G3 : fonctions bureau et sauvegarde locale.
- G4 : recette et installateur Windows.

Aucune publication, fusion, ni validation pédagogique implicite. Les fonctionnalités sont validées uniquement avec des preuves de tests.
